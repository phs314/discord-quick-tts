# 같은 디스코드 서버에서는 먼저 쓰고 있는 음성 채널이 우선이다

디스코드 봇은 디스코드 서버마다 음성 채널 하나에만 들어갈 수 있습니다. 혼자 쓸 때는 문제가 없었지만, 친구들과 함께 쓰면 같은 디스코드 서버의 서로 다른 음성 채널에서 동시에 문장을 보낼 수 있습니다. 전에는 문장을 보낸 사람의 채널로 봇이 그냥 옮겨 갔고 재생 순서는 디스코드 서버마다 하나였기 때문에, A 가 보낸 문장이 B 의 채널에서 읽히거나 대화 중인 채널에서 봇이 갑자기 빠져나갈 수 있었습니다.

세 가지를 놓고 골랐습니다.

- **먼저 온 채널 우선** (고름): 봇이 쓰이고 있는 음성 채널이 있으면, 같은 디스코드 서버의 다른 채널에서 온 문장은 거절합니다.
- 요청한 채널로 옮겨 가기: 지금처럼 옮기되 원래 채널의 남은 문장만 버립니다. 두 채널이 번갈아 쓰면 봇이 계속 오갑니다.
- 봇 여러 개: 봇 계정을 여러 개 두고 채널마다 하나씩 붙입니다. 가장 유연하지만 봇 앱과 토큰을 여럿 관리해야 합니다.

대화 중인 채널에서 봇이 끌려 나가지 않는 것이 가장 중요했고, 이미 "사람이 아무도 없으면 나간다" 규칙이 있어서 그 채널이 비면 바로 다른 채널에서 쓸 수 있으므로 먼저 온 채널 우선을 골랐습니다.
