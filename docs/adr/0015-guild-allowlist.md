# 봇이 머물 디스코드 서버를 허용 목록으로 정한다 (guild 컨텍스트)

- 상태: 채택
- 날짜: 2026-10-11

봇을 친구 몇 명부터 쓰게 하고 점차 완전 공개로 넓히려고 합니다. 지금은 초대 링크만 있으면 어느 디스코드 서버에나 들어가서, 링크가 퍼지면 봇 서버 한 대와 무료 비공식 TTS(ADR 0006)가 감당하지 못할 만큼 쓰일 수 있습니다. 그래서 공개 전까지는 봇 주인이 허용한 디스코드 서버에만 봇이 남게 합니다.

## 결정

- 새 바운디드 컨텍스트 `guild`(지원)를 둡니다. "봇이 어느 디스코드 서버에 머물러도 되나" 는 문장 읽기(`speech`)나 PC 연결(`device`)과 쓰는 말(봇 주인, 허용 목록, 초대)도 바뀌는 이유도 달라서입니다. `guild` 와 다른 두 컨텍스트는 서로 모릅니다.
- `GuildId` 를 `speech` 에서 `shared` 로 옮깁니다. `speech` 와 `guild` 가 모두 디스코드 서버를 가리키므로 ADR 0002 의 "둘 다 쓰는 것만 shared" 에 맞습니다.
- 허용 목록은 설정 파일이 아니라 DB(`allowed_guild` 테이블)에 둡니다. 봇 서버를 다시 켜지 않고 디스코드의 `/허용목록 추가·삭제·보기` 로 바꿉니다.
- 허용 목록을 쓸지는 설정 `quicktts.guild-allowlist.enabled`(환경변수 `QUICKTTS_GUILD_ALLOWLIST_ENABLED`, 기본 `true`)로 정합니다. 완전 공개할 때 코드 수정 없이 `false` 로 끕니다. 자주 바꿀 값이 아니라서 명령 대신 설정으로 둡니다.
- 봇 주인은 Discord Developer Portal 에서 봇 앱을 만든 사람(팀 소유면 팀 주인)이고, 봇 서버가 켜질 때 디스코드에서 받아 옵니다. 따로 설정할 값이 없습니다.
- `/허용목록` 은 디스코드 서버 관리자에게만 보이게 등록하고(`DefaultMemberPermissions.DISABLED`), 봇 주인인지는 `ManageGuildAllowlistService` 가 한 번 더 확인합니다. 봇과의 개인 메시지에서도 쓸 수 있습니다.
- 목록 밖 디스코드 서버에 초대되면 시스템 메시지 채널(없으면 기본 채널)에 "허용된 서버에서만 쓸 수 있다" 는 안내와 그 서버 ID 를 남기고 나갑니다. 글을 쓸 수 없는 서버면 안내 없이 나갑니다.
- 봇 서버가 꺼져 있는 동안 초대된 곳도 있으므로, 켜질 때 들어가 있는 모든 디스코드 서버를 확인합니다. 이때 허용 목록이 비어 있으면(처음 켠 때) 지금 들어가 있는 디스코드 서버를 모두 넣습니다. 봇 주인이 이미 쓰던 서버에서 쫓겨나지 않게 하려는 것입니다.
- 목록에서 빼면 봇이 그 디스코드 서버에 있을 때 같은 안내를 남기고 바로 나갑니다. 허용 목록이 꺼져 있으면 넣고 빼도 목록만 바뀝니다.

## 고르지 않은 것

- 설정 파일에 서버 ID 목록 두기: 친구 서버를 넣을 때마다 봇 서버를 다시 켜야 합니다.
- `speech` 안에 두기: 파일은 적지만 "봇 주인", "초대" 같은 말이 문장 읽기 컨텍스트에 섞입니다.
- 봇 주인 ID 를 설정으로 받기: 디스코드가 이미 알고 있는 값이라 설정할 거리만 늘어납니다.
- 목록 밖 서버에서 나가지 않고 명령만 막기: 봇이 서버 목록에 남아 있어 헷갈리고, 음성 채널 입장 같은 다른 경로도 모두 막아야 합니다.

## 결과

- 친구가 봇을 쓰려면 봇 주인이 `/허용목록 추가` 로 그 서버 ID 를 넣고, 답장에 나오는 초대 링크(그 서버가 미리 골라진 링크)로 초대합니다. 먼저 초대했다가 쫓겨났으면 안내에 남은 서버 ID 를 봇 주인에게 알려 주면 됩니다.
- 디스코드 서버 ID 는 디스코드의 정수 옵션 범위를 넘을 수 있어 글자로 받고 `GuildId.parse` 로 읽습니다.
- 허용 목록을 다 비운 뒤 봇 서버를 다시 켜면 그때 들어가 있는 디스코드 서버가 다시 들어갑니다. 목록에서 빼면 봇이 나가므로 보통은 들어가 있는 서버가 없습니다.
- 서비스는 11개가 됐습니다(`ManageGuildAllowlistService`, `EnforceGuildAllowlistService`, ADR 0008).
- 완전 공개 전에는 사용량 제한과 TTS 차단 대비가 따로 필요합니다. 이 결정은 그때까지 쓰는 사람 수를 봇 주인이 조절하게 해 줄 뿐입니다.
