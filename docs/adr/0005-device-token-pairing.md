# PC 는 /연결 코드로 받은 기기 토큰으로 인증한다

봇 서버는 quick chat 을 보낸 사람이 어느 디스코드 사용자인지 알아야 그 사람의 음성 채널에서 읽을 수 있습니다. 처음에는 모두가 같은 API 키를 쓰고 클라이언트에 자기 디스코드 사용자 ID 를 직접 적게 했는데, 키만 알면 남의 ID 로 말할 수 있고 사용자 ID 를 찾아 적는 것도 번거로웠습니다. 그래서 디스코드가 이미 확인한 사람에게 코드를 주고, 그 코드로 PC 마다 따로 토큰을 받게 했습니다.

1. 디스코드에서 `/연결` 을 치면 나만 보이는 8자리 연결 코드가 옵니다. 5분 동안 한 번만 쓸 수 있습니다.
2. 클라이언트가 코드와 PC 이름을 `POST /api/devices` 로 보내면, 봇 서버는 그 PC 만의 기기 토큰을 돌려줍니다.
3. 이후 클라이언트는 모든 요청에 `Authorization: Bearer <기기 토큰>` 을 붙이고, 봇 서버는 토큰으로 주인을 찾습니다.

## 결과

- 봇 서버는 기기 토큰을 SHA-256 해시로만 저장합니다. 토큰이 32바이트 난수라서 솔트 없는 해시로도 거꾸로 찾을 수 없고, 해시로 바로 조회할 수 있습니다.
- 대기 중인 연결은 메모리에만 둡니다. 5분이면 사라질 값이라 봇 서버를 다시 켜면 받은 코드가 없어지는 것은 받아들였습니다.
- PC 를 잃어버리면 `/연결해제` 로 그 기기만 끊습니다. 끊긴 클라이언트는 다음에 보낼 때 401 을 받고 연결 코드를 다시 묻습니다.
- 클라이언트는 기기 토큰을 `~/.discord-quick-tts/client.properties` 에 저장합니다.
